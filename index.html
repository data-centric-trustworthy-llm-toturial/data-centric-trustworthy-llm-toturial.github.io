Overview

Large language model agents are evolving from conversational assistants into autonomous systems that plan, reason, use tools, maintain memory, and collaborate across high-stakes settings such as healthcare, finance, science, and software engineering. This tutorial presents a data-centric roadmap for building agents that are robust, secure, domain-grounded, and measurable.

The tutorial connects core KDD themes, including robust learning from noisy data, generalization across tasks, and responsible decision-making, to emerging challenges in agent systems. Participants will leave with practical design patterns, evaluation strategies, and open research questions for trustworthy LLM-based agents.

At a Glance

Venue: ACM KDD 2026

Location: ICC Jeju, Jeju, Korea

Format: Lecture-style tutorial

Duration: 3 hours

Prerequisites: Basic machine learning and familiarity with LLMs

01

Generalizability

How agents behave under distribution shift, noisy data, changing tasks, and component-level changes.

02

Security

Threat models for prompt injection, memory poisoning, unsafe tools, multi-agent propagation, and defenses.

03

Domain Trust

Case studies in science, engineering, medicine, and commerce where domain constraints shape agent behavior.

04

Evaluation

Benchmarks and metrics that expose trade-offs among robustness, security, fairness, utility, and reliability.

What Participants Will Learn

  • Define trustworthiness for LLM-based agents beyond a single aggregate score.
  • Identify agent failure modes caused by shifting, degraded, or adversarial data.
  • Apply security patterns such as least-privilege access, sandboxing, information-flow control, and runtime auditing.
  • Translate domain constraints into agent design and evaluation requirements.
  • Design benchmarks that reveal trade-offs instead of masking failures.
